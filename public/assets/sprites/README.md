# Character sprite assets

The PNGs generated by `scripts/generate_sprite_frames.py` are clearly marked prototype placeholder frames. They demonstrate the safe-cell pipeline only; replace them with approved final character illustrations before public release.

Generate locally:
```bash
python -m pip install pillow
python scripts/generate_sprite_frames.py
```

Each animation writes separate transparent RGBA frames and a padded atlas. Atlas layout uses 256x256 frame cells with 24px gutters, no trimming, 24px minimum silhouette safe zone, and consistent bottom-center foot anchors. The manifest records every frame's exact rectangle, duration and pivot.
