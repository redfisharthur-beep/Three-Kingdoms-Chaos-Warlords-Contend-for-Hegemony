# 武將圖像與動畫逐格素材規格

## 本階段產出
- 5 名武將：呂布、趙雲、諸葛亮、關羽、黃忠。
- 每名武將 6 組動作：idle 8 幀、run 8 幀、attack 6 幀、ultimate 10 幀、hit 3 幀、death 6 幀。
- 共 205 張獨立逐格圖，另有 5 張武將立繪及 3 張敵兵／精英／Boss 插圖。
- 素材採透明背景 SVG，256 × 256 px；每格固定腳底錨點 (128, 226)。
- 所有畫格保留至少 24 px 安全留白；不裁切、不緊貼拼接。
- Phaser 逐格載入，不依賴把一張緊密圖集硬切成多格；避免武器、頭盔、披風因裁切而破圖。

## 產生方式
```bash
npm run sprites
npm run dev
```
素材會產生於 `public/assets/sprites/{hero}/{animation}/{frame}.svg`。每個 frame 都是獨立圖片檔；`manifest.json` 記錄幀數、FPS、來源路徑、錨點與留白規格。正式建置 `npm run build` 會自動先執行素材產生器。

## 注意
這批是可運作的向量風格原型素材，並非最終手繪高精度角色美術。正式發行前仍可替換成美術師定稿；維持相同 256 × 256 畫格、透明背景與腳底錨點即可，不需改動動畫載入程式。
