# 美術素材製作規格

## 動畫逐格圖（Sprite Sheets）
所有角色動畫以透明 PNG 輸出，採「一格一檔」為母檔，再由建置流程合成 sprite sheet。不得直接把緊密排列的角色拼成無留白圖再依固定寬高硬切。

### 統一規格
- 角色母格：256 × 256 px（可依大型武將升至 320 × 320）。
- 每格透明 RGBA PNG，角色置中，腳底基線固定於 y=226。
- 單格安全留白：四邊至少 24 px；武器、髮飾、披風與特效需納入外接框。
- 每格角色可視範圍不得超過 208 × 208 px；特效可放在獨立圖層。
- sprite sheet 以 4 欄排列、格間距 24 px、每格外框 256 × 256 px；不可將格間距計入 frame 尺寸。
- 透明像素必須保留，不得以白底代替。
- 每個動畫另附 JSON frame metadata：frame x/y/width/height、duration、pivot、footAnchor。
- 動畫應採每張獨立 frame PNG 為來源，合成時採 padding/extrude，確保不裁掉輪廓。

## 動畫清單（首批）
每名武將至少：
1. idle：8 幀
2. run：8 幀
3. attack：6 幀
4. ultimate：8～12 幀
5. hit：3 幀
6. death：6 幀

### 特效分層
- 武器光弧、刀氣、法陣、箭矢、爆炸使用獨立 FX 圖集。
- 不將大範圍特效烘焙進角色框，以免影響角色對齊與碰撞判定。
- pivot 與 footAnchor 應維持一致，避免播放時角色上下跳動。

## 風格
日式清新奇幻、莫蘭迪低飽和色系、明確輪廓、透明背景。五名武將必須保持剪影和武器可辨識度。
